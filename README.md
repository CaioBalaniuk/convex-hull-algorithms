# Convex Hull Algorithms

## Overview

This project implements and compares three classic algorithms for computing the **convex hull** of a set of two-dimensional points:

- **Jarvis March (Gift Wrapping)** — builds the hull by repeatedly selecting the next boundary point. Its time complexity is typically expressed as \(O(nh)\), where `n` is the number of input points and `h` is the number of hull vertices.
- **Andrew's Monotone Chain** — sorts the points lexicographically and constructs the lower and upper parts of the hull in \(O(n \log n)\) time.
- **Graham Scan** — sorts points by polar angle around a pivot and uses a stack to determine the hull, also in \(O(n \log n)\) time.

The program generates a set of points, runs the algorithms, measures their execution times, checks whether their results agree, and saves data for a Python visualization.

## Requirements

Install the following tools:

- **GCC** (or another C compiler compatible with the project's C11 code)
- **GNU Make**
- **Python 3**
- **Matplotlib** for plotting

The C code is compiled with C11 support and optimization enabled by the provided Makefile.

### Install Matplotlib

```bash
python -m pip install matplotlib
```

On some systems, the Python command may be `python3`:

```bash
python3 -m pip install matplotlib
```

### Windows notes

On Windows, use a terminal where `gcc` and `make` are available, such as an MSYS2/MinGW environment or a configured development shell. The provided Makefile uses GCC-style commands and creates `hull.exe`.

Check that the tools are available:

```bash
gcc --version
make --version
python --version
```

If your environment uses `python3` instead of `python`, adjust the Python command in the Makefile accordingly.

## Project structure

```text
algorithmes/
├── include/
│   ├── jarvis.h
│   ├── andrews.h
│   └── graham.h
├── src/
│   ├── jarvis.c
│   ├── andrews.c
│   └── graham.c
├── main.c
├── visualize.py
├── Makefile
└── README.md
```

- `include/` contains the public declarations for each algorithm.
- `src/` contains the C implementations of the algorithms.
- `main.c` generates the input points, benchmarks the algorithms, checks their results, and writes the data used by the visualizer.
- `visualize.py` reads `hull_data.txt` and displays the points and the selected convex hull.
- `Makefile` provides commands to compile and run the project.
- `hull_data.txt` is generated by the C program; it is not required to be created manually.

## How to run

Run the commands from the project root, where the `Makefile` is located.

### 1. Compile the C program

```bash
make
```

This builds the executable (`hull.exe` on the configured Windows setup).

### 2. Run the benchmark and visualize an algorithm

```bash
make run ALGORITHM=graham
```

Choose any of the supported algorithms:

```bash
make run ALGORITHM=jarvis
make run ALGORITHM=andrews
make run ALGORITHM=graham
```

The run target executes the C program, which generates the points, measures the execution time of all three algorithms, compares the hulls, and writes `hull_data.txt`. It then launches `visualize.py` to display the selected algorithm's hull.

You can also run the executable directly to run the benchmark and generate `hull_data.txt` without opening the plot:

```bash
./hull.exe
```

On Windows Command Prompt, use:

```bat
hull.exe
```

### 3. Clean generated files

```bash
make clean
```

This removes the compiled executable and generated hull data, according to the provided Makefile.

## How it works

1. **Generate points:** `main.c` creates a set of 2D points. The current configuration uses `N = 50000` points and a fixed random seed, so the generated input is reproducible when the same C library and runtime are used.
2. **Compute the convex hull:** each algorithm receives the input points and returns the vertices on the boundary of the smallest convex polygon containing all the points.
3. **Measure execution time:** the program runs each algorithm repeatedly and reports the average CPU time per run. The repetition count is configured in `main.c`.
4. **Verify results:** the program compares the vertex sets returned by the three algorithms. Matching sets indicate that the algorithms agree on the hull for the generated input; this check does not independently prove correctness for every possible input.
5. **Save visualization data:** the program writes the input points and Andrew's hull to `hull_data.txt`. The current `main.c` configuration exports Andrew's hull for visualization.
6. **Plot:** `visualize.py` reads `hull_data.txt` and draws the input points and hull outline using Matplotlib. The `ALGORITHM` argument selects the title/label shown in the plot; it does not cause Python to recompute the hull.

## What is a convex hull?

Imagine stretching a rubber band around a set of points. When released, the band forms the convex hull: the smallest convex shape containing every point. Points strictly inside the shape are not hull vertices.

## Output

A typical run prints:

- The execution time of each algorithm
- The number of hull vertices returned by each algorithm
- Whether the algorithms agree on their results

It also opens a plot showing the input points and the hull outline.

Exact execution times and the number of hull vertices depend on the input and the machine running the program.

## Notes

- The algorithms operate on 2D points represented by `x` and `y` coordinates.
- The reported timings are experimental measurements, not formal proofs of theoretical complexity.
- If `make run` cannot find Python or Matplotlib, install Matplotlib and check the Python command used by the Makefile.
